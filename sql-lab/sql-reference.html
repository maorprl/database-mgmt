Core — פונקציות שרואים בקורס

COUNT(*)

סופר rows, גם אם חלק מהעמודות בהן מכילות NULL.

COUNT(*)
דוגמה
SELECT COUNT(*) AS route_count
FROM routes;
מחזיר: 13.

COUNT(column)

סופר רק values שאינם NULL.

COUNT(column)
דוגמה
SELECT COUNT(arrived_at) AS reported_arrivals
FROM stops;
Stops ללא זמן הגעה לא נספרות.

COUNT(DISTINCT ...)

סופר values שונים שאינם NULL.

COUNT(DISTINCT column)
דוגמה
SELECT COUNT(DISTINCT region) AS region_count
FROM depots;
מחזיר: 5.

SUM(...)

מסכם values מספריים; NULL אינו מתווסף לסכום.

SUM(expression)
דוגמה
SELECT SUM(distance_km) AS total_km
FROM routes
WHERE depot_id = 2;
Riverbend Crossdock: 235 ק״מ.

COALESCE(...)

מחזירה את ה-value הראשון שאינו NULL.

COALESCE(value1, value2, ...)
דוגמה
SELECT stop_id,
       COALESCE(delivered_packages, 0) AS delivered
FROM stops;
NULL ב-delivered_packages מוצג כ-0.

CASE

ביטוי תנאי. שימושי במיוחד ב-conditional aggregation.

CASE WHEN condition THEN value ELSE value END
דוגמה
SELECT service_date,
       SUM(CASE WHEN status = 'completed'
                THEN 1 ELSE 0 END) AS completed_routes
FROM routes
GROUP BY service_date;

טקסט

LENGTH(...)

מחזירה את מספר התווים בטקסט.

LENGTH(text)
דוגמה
SELECT depot_name,
       LENGTH(depot_name) AS name_length
FROM depots;

UPPER(...)

ממירה טקסט לאותיות גדולות.

UPPER(text)
דוגמה
SELECT depot_name,
       UPPER(region) AS region_upper
FROM depots;

LOWER(...)

ממירה טקסט לאותיות קטנות.

LOWER(text)
דוגמה
SELECT route_code,
       LOWER(status) AS status_lower
FROM routes;

||

שרשור מחרוזות ב-SQLite.

text1 || text2
דוגמה
SELECT route_code || ' · ' || status AS route_label
FROM routes;

SUBSTR(...)

חותכת חלק ממחרוזת. ב-SQLite האינדקס מתחיל ב-1.

SUBSTR(text, start, length)
דוגמה
SELECT route_code,
       SUBSTR(route_code, 1, 2) AS depot_prefix
FROM routes;
לדוגמה: NG-0820-A → NG.

תאריך · SQLite

DATE(...)

מחזירה תאריך בפורמט YYYY-MM-DD מתוך ערך תאריך/שעה.

DATE(value)
דוגמה
SELECT stop_id,
       DATE(arrived_at) AS arrival_date
FROM stops
WHERE arrived_at IS NOT NULL;

STRFTIME(...)

מחלצת או מעצבת חלקי תאריך ושעה.

STRFTIME(format, value)
דוגמה
SELECT service_date,
       STRFTIME('%Y', service_date) AS service_year
FROM routes;
%Y = שנה, %m = חודש, %d = יום.

DATETIME(...)

מחזירה ערך תאריך ושעה בפורמט אחיד.

DATETIME(value)
דוגמה
SELECT stop_id,
       DATETIME(arrived_at) AS arrival_datetime
FROM stops
WHERE arrived_at IS NOT NULL;

Aggregates נוספים

AVG(...)

ממוצע של values שאינם NULL.

AVG(expression)
דוגמה
SELECT AVG(distance_km) AS avg_route_km
FROM routes;

MAX(...)

ה-value הגבוה ביותר בקבוצה.

MAX(expression)
דוגמה
SELECT depot_id,
       MAX(distance_km) AS longest_route
FROM routes
GROUP BY depot_id;

MIN(...)

ה-value הנמוך ביותר בקבוצה.

MIN(expression)
דוגמה
SELECT depot_id,
       MIN(distance_km) AS shortest_route
FROM routes
GROUP BY depot_id;

טווח ולוגיקה

אלה operators / patterns ולא functions, אבל שימושיים כ-reference.

BETWEEN

בודק טווח כולל שני הקצוות.

value BETWEEN low AND high
דוגמה
SELECT route_code, distance_km
FROM routes
WHERE distance_km BETWEEN 50 AND 100;

IN

בודק אם value נמצא ברשימת values או בתוצאת subquery.

value IN (...)
דוגמה
SELECT route_code, status
FROM routes
WHERE status IN ('delayed', 'cancelled');

NOT IN

בודק ש-value אינו נמצא בקבוצה — אבל צריך להיזהר מאוד עם NULL בתוצאת subquery.

value NOT IN (subquery)
דוגמה מסוכנת
SELECT shipment_id
FROM shipments
WHERE shipment_id NOT IN (
  SELECT shipment_id
  FROM route_shipments
);
מלכודת NULL: אם ה-subquery מחזירה אפילו NULL אחד, ההשוואה עלולה להפוך ל-UNKNOWN ולהחזיר תוצאה מפתיעה. לבדיקת היעדר, העדיפו בדרך כלל NOT EXISTS.
הגרסה הבטוחה יותר
SELECT s.shipment_id
FROM shipments s
WHERE NOT EXISTS (
  SELECT 1
  FROM route_shipments rs
  WHERE rs.shipment_id = s.shipment_id
);

Subqueries

Derived table · subquery ב-FROM

משתמשים בתוצאת SELECT כ-relation זמנית.

FROM (SELECT ...) alias
דוגמה
SELECT depot_name, total_km
FROM (
  SELECT d.depot_name,
         SUM(r.distance_km) AS total_km
  FROM depots d
  JOIN routes r ON r.depot_id = d.depot_id
  GROUP BY d.depot_id, d.depot_name
) x
WHERE total_km >= 200;
כשיש כמה שלבים, CTE עם WITH בדרך כלל קריא יותר.

Scalar subquery · subquery ב-SELECT

Subquery שמחזירה value יחיד ולכן יכולה להופיע כביטוי.

SELECT (SELECT single_value ...)
דוגמה
SELECT r.route_code,
       (
         SELECT d.depot_name
         FROM depots d
         WHERE d.depot_id = r.depot_id
       ) AS depot_name
FROM routes r;

Window Functions

ROW_NUMBER() OVER (...)

נותנת מספר רץ לכל row בתוך קבוצה, בלי לצמצם את ה-Grain.

ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...)
דוגמה
SELECT route_code,
       depot_id,
       distance_km,
       ROW_NUMBER() OVER (
         PARTITION BY depot_id
         ORDER BY distance_km DESC, route_id
       ) AS distance_rank
FROM routes;
כל route נשארת row; רק נוסף לה דירוג בתוך ה-depot.

SUM(...) OVER (...)

מחשב סכום חלון ומחזיר אותו לצד כל row, במקום לקרוס ל-row אחת כמו GROUP BY.

SUM(expression) OVER (PARTITION BY ...)
דוגמה
SELECT route_code,
       depot_id,
       distance_km,
       SUM(distance_km) OVER (
         PARTITION BY depot_id
       ) AS depot_total_km
FROM routes;
כל route נשארת נפרדת, אבל לכל אחת מופיע גם סך הק״מ של ה-depot שלה.
